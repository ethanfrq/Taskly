# Code of Conduct

Taskly adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

## In short

- Be kind and assume good intent.
- Give and accept feedback on the work, never on the person.
- No harassment, insults, discriminatory language or unwelcome attention, in any form.
- Respect people's time, privacy and boundaries.

## Scope

This applies in every project space: issues, pull requests, reviews, discussions, and anywhere you represent the project.

## Reporting

If someone's behavior makes you uncomfortable, contact the maintainer, [@ethanfrq](https://github.com/ethanfrq). You can also use GitHub's [report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) feature on any comment or user.

Reports are handled confidentially. Maintainers may remove comments, close threads, or block contributors who break this code of conduct.
