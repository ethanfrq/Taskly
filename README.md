Taskly is an open-source daily to-do app you install on your phone. Connect it to Claude once, and every morning Claude reads your mail, calendar and messages and fills your day with what needs doing. Taskly takes it from there: one clear checklist, and reminders at the right minute.

> [!NOTE]
> Taskly is in beta: every planned feature is in, tested and documented, but no public instance has run it for long yet. [Feedback welcome.](https://github.com/ethanfrq/Taskly/issues)

<a id="install"></a>

### 📱 Install it

1. Open your Taskly instance in **Safari** (iPhone) or **Chrome** (Android, desktop).
2. Add it: **Share › Add to Home Screen** on iPhone, **Install app** on Android and desktop.
3. Launch Taskly from the home screen and follow the onboarding: account, color, notifications, Claude.

> [!IMPORTANT]
> On iPhone, notifications only work once Taskly is on the home screen (iOS 16.4 or later).

<a id="connect-claude"></a>

### 🤖 Connect Claude

1. In Taskly, open **Settings › Connect Claude** and copy the connector address.
2. In Claude, add it as a **custom connector**, then sign in to Taskly to approve.
3. Every morning, ask Claude: **“Prepare my day in Taskly”**. Later in the day, **“Refresh my day in Taskly”** updates what changed: done, moved or cancelled.

| Your Claude plan | What to know |
|---|---|
| Free | One custom connector allowed: Taskly can be it. Access to mail and calendar connectors may be limited. |
| Pro / Max | Add Taskly in Claude's connector settings. |
| Team / Enterprise | An organization owner adds Taskly once for everyone. |

The tools Claude gets and how access is secured: [docs/connect-claude.md](docs/connect-claude.md).

<a id="how-it-works"></a>

## 🧠 How it works

Taskly never calls Claude. It's the other way around: Taskly exposes an [MCP](https://modelcontextprotocol.io) server, and Claude, which already reads your mail and calendar through its own connectors, writes the tasks into Taskly.

```mermaid
flowchart LR
  subgraph claude["Claude (your own plan)"]
    C[Claude]
    C --- G[Gmail / Outlook]
    C --- K[Calendar]
    C --- S[Slack / Teams / Notion]
  end
  C -- "MCP over OAuth" --> M[Taskly MCP server]
  M --> DB[(Postgres)]
  DB --> A[Taskly app on your phone]
  Q[Reminder scheduler] -- "Web Push" --> A
```

- Your Claude plan is enough: whoever hosts Taskly needs no Anthropic API key and pays no AI bill.
- Taskly never receives your emails, only the tasks Claude creates, each with a link back to the source.
- Taskly works without Claude: manual tasks, reminders and the checklist stand on their own.

## 💻 Development

```bash
git clone https://github.com/ethanfrq/Taskly.git && cd Taskly
```

```bash
npm install
```

```bash
npm run dev
```

Open http://localhost:3000. The local database lives in `.data/`, sign-in codes are printed in the terminal and push keys are generated for you. Before pushing:

```bash
npm run lint && npm run typecheck && npm test
```

Commands, branch and commit conventions: [CONTRIBUTING.md](CONTRIBUTING.md). Technical choices and their trade-offs: [docs/adr](docs/adr/README.md).

<a id="privacy"></a>

## 🔒 Privacy and security

- Taskly stores the tasks Claude creates and a link to their source, never the content of your messages.
- You decide what Claude gets on Taskly's consent screen. **Settings › Connect Claude › Disconnect Claude** revokes it at once, even tokens that haven't expired.
- Export everything as JSON or delete your account from Settings.
- Found a vulnerability? Report it privately: [SECURITY.md](SECURITY.md).

What happens when you say *“Prepare my day in Taskly”*:

```mermaid
sequenceDiagram
  participant U as You
  participant C as Claude
  participant S as Gmail · Calendar · Slack
  participant T as Taskly MCP
  participant DB as Postgres
  participant Q as QStash
  participant P as Your phone
  U->>C: "Prepare my day in Taskly"
  C->>T: get_today (OAuth bearer token)
  C->>S: read mail, events, messages
  C->>T: add_calendar_events (replace_day)
  C->>T: add_tasks (one batch, with sources)
  T->>DB: save, skip duplicates, plan reminders
  T->>Q: schedule each reminder at its minute
  Q->>T: signed callback, right on time
  T->>P: Web Push notification
```

<details>
<summary><b>🔐 Security model</b></summary>

<br>

- Taskly is its own OAuth 2.1 server ([Better Auth](https://www.better-auth.com)): PKCE, Dynamic Client Registration and Client ID Metadata Documents, and a consent screen the user approves.
- Tokens are bound to the MCP endpoint ([RFC 8707](https://www.rfc-editor.org/rfc/rfc8707)): signed JWTs checked for signature, audience, expiry and scopes (`tasks:read`, `tasks:write`) on every call. Each call only sees the data of the user who approved it.
- Revocation is immediate. “Disconnect Claude” deletes the grants, and the endpoint refuses any token issued before that moment, even one that hasn't expired.
- No passwords are stored: sign-in uses passkeys (WebAuthn) or 6-digit email codes, valid 10 minutes with 5 attempts.
- Every scheduler call is authenticated. QStash callbacks are signature-checked; the cron endpoints (reminder sweep, daily housekeeping) need a secret compared in constant time.
- The app fails closed. In production, a missing auth secret, email provider or database stops it with a clear error instead of falling back silently.

</details>

<details>
<summary><b>⏰ Reminder engine</b></summary>

<br>

- The `reminders` table is the source of truth: every change to a task re-plans its reminders.
- Each reminder is scheduled for its exact minute (QStash `notBefore`, deduplicated). Without QStash, a sweep picks them up: an external cron, or the built-in scheduler every 20 seconds.
- Sending first claims the reminder with a conditional `UPDATE`, so two schedulers waking at once can't send it twice.
- Quiet hours defer a reminder rather than drop it. Follow-ups depend on the insistence level, and the app badge shows what's left.
- Every “today” is computed in the user's time zone, safe across daylight saving changes.

</details>

<details>
<summary><b>📴 Offline</b></summary>

<br>

The service worker caches the app's pages, so Today and the Agenda open without a network. Tasks checked offline go into an outbox that is replayed when the connection comes back: on reconnect, when the app comes to the foreground, and every 15 seconds while changes wait.

</details>
